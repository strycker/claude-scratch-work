confusion tables) persisted to disk. The three metric functions are adapted math — the exact
formulas were read from the Phase-3 salvage helpers — but re-expressed as pure functions over
plain `(y_true: list, proba: np.ndarray, classes: list)` inputs, with a NEW orchestrator

own per-step `(dates, proba, classes)` accumulators (Plan 02) plus a `y_true` list joined by
the report layer (Plan 06) from the full-sample smoothed reference labeling by date (review F2).

before scoring (review F3).

comparison. The critical constraint (Pitfall 5, D-01): extract ONLY the pure math — never
import the salvage file or its incumbent bundle-report dataclass, which expect fold-report /
per-horizon shapes the platform's walk-forward driver does not produce.
Output: `evaluation/model_metrics.py` + its test file.
