<objective>
Build the EVAL-01 walk-forward backtest driver: `run_backtest()` steps the frozen
`expanding_steps()` generator across the holdout-bounded monthly index (1972-01 → 2020-12),
refitting L1 (jump-model labeler) and L2 (calibrated nowcaster) on `train_index`-only data at
every step, computing L3 returns-by-regime + EWMA vol and L4 vol-targeted regime tilt to size
target weights, then accruing a cost-adjusted equity curve. It logs exactly one registry trial
per run and collects the per-step `(y_true, proba, classes)` triples that EVAL-04 (Plan 04)
consumes.

Purpose: This is the phase's central artifact and the design §14 "Phase 1 exit" — the first
honest end-to-end number for the platform. The whole engineering risk is orchestration
correctness: walk-forward discipline (data ≤ t only), holdout boundary, cost accounting, and
early-history resilience — not new math (every primitive is frozen from Phases 1–4).
Output: `backtest/driver.py` + its unit test file.
</objective>
