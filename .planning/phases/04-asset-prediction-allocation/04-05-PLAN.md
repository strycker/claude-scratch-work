| T-04-15 | Tampering | malformed / malicious holdings YAML (e.g. !!python tags, non-numeric weight) | high | mitigate | `yaml.safe_load` only (never `yaml.load`); numeric coercion wrapped in `try/except (TypeError, ValueError)` (V5) — a hostile file cannot execute code or crash the report |
| T-04-16 | Information Disclosure | real account holdings committed to git | high | mitigate | `.gitignore` ignores `config/accounts/*.yaml` except the obviously-fake `example.yaml`; `git check-ignore` is an acceptance gate — Glenn's real files can never be accidentally tracked |
