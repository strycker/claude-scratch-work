| rows_added | An accounting mismatch passes silently or raises only under assertions. |
| effective-flag rows | The row records the requested flag (M5), or omits it (RED on HEAD). |
| harness_plan | The row claims a run plan it did not come from (M6). |
| real-ledger sha fixture | Any test or step touches `registry/trials.jsonl`. |
