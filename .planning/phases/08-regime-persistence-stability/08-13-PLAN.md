<objective>
Close G-08-2's three diagnosed defects and the two undiagnosed ones behind them. The weekly report
must have a supported command that builds everything it reads, from the recipe that was evaluated,
at zero registry cost. It must also score what that model was trained on.

Purpose: UAT test 2 (blocker). Glenn ran the supported commands (reinstall, `build_platform_data.py`,
`evaluation.report --smoke`) and `python -m trading_crab_lib.platform.report.weekly` failed on a
missing `nowcaster.pkl`. The verified root cause has three parts:
1. Nothing supported writes the model: the only writer is `evaluate_nowcaster`, which appends a trial
   and which nothing calls.
2. weekly.py scores all 55 columns of a row, and 543 of 708 months carry a NaN.
3. The backtest's L2 fits and scores only `_cv_safe_active_features`, so serving does not mirror what
   was evaluated.

**Planning-time finding: the UAT's count is short by two.** A grep shows weekly.py also loads
`returns_by_regime` and `asset_returns`, and no supported command writes either. Fixing the model
alone would have moved the FileNotFoundError one line down. The planner confirmed, in a scratch
prototype, that these three artifacts are the complete set: with them built, and the scored row
complete, `weekly.main` ran end to end on the tracked data.

**Approved direction (Glenn, 2026-09-28), implemented exactly:**
- The serving builder mirrors `_refit_l2`: active-feature rule, embargo, calibrated LR, same labels
  source. It reuses the code through one shared helper, rather than re-implementing it.
- The serving fit is NOT a registry trial: `NO_REGISTRY`, total stays 44, the ledger stays
  byte-identical, and no in-sample accuracy is reported.
- weekly scores the model's own columns.
- A missing model gets a clear error naming the command.
- There is an end-to-end test against a real fitted model, with a negative arm.
- A parity test shows the builder's columns equal `_cv_safe_active_features` for the same frame.

**Labels source, stated rather than assumed.** At each step the backtest trains L2 on the in-window
L1 labels. Its full-history analog is the evaluated run's own full-sample labeling. Measured at plan
time, `regime_labels` equals `outputs/reports/platform/backtest_full_sample_states.parquet`
elementwise (0 of 695 months mismatched). weekly.py already uses `regime_labels` for the filter's
prior and transition matrix. Training the nowcaster on the same series keeps the drivers' invariant
that L2 and the filter share one label series.

**Interim NaN policy.** 08-12 asks Glenn what the surface does when the latest row lacks a model
column. Today it does: 2026-08-31 lacks `fred_m2sl`, `fred_totalsl` and `div_yield`. Until 08-14
applies his ruling, this plan implements the conservative option the orchestrator listed first: fail
loudly, naming the columns. **So after this plan, UAT test 2 still fails on today's real data, by
design, with a clear message.** 08-14 closes it.

**Measured facts this plan will reproduce, not change** (08-12 records them; the recipe is the
evaluated one):
- All 55 columns are admitted.
- The training block runs 2007-04-30 to 2019-12-31: 153 rows holding 3 of 6 states.
- The served posterior is one distinct vector across every complete month.

That last one is not a defect of this plan, and "fixing" it here would be an unregistered new
configuration.

**Scope fences.** No recipe change of any kind. No registry row. No holdout read in any fitting path.
`run_joint_lift.py` (the decision-bearing harness) is untouched, even though it carries its own copy
of the tradable mapping. That duplicate is recorded, not fixed. `evaluate_nowcaster` is untouched. It
still writes `nowcaster.pkl` and appends a trial if anyone calls it; that is recorded as an open item.
`legacy/` and the submodules are untouched, and the ratchet stays at 31. `serving.py` may import only
`trading_crab_lib.platform.*`: importing `trading_crab_lib` or `trading_crab_lib.checkpoints` would
be a 32nd legacy site.

## Honest-evidence note: how each new check can fail

| Check | Fails when |
|---|---|
| Characterization pin (`_refit_l2` == inline recipe) | The extraction changes the recipe: embargo, active-feature rule, split count, or column order. The recorded `embargo_months=0` mutation proves it bites. |
| Tracer e2e (serving.main then weekly.main) | Any serving artifact is missing or malformed, weekly cannot consume the model, the report omits the A7 or band text, or anything writes a registry row. The tmp copy's bytes, the real file's sha256 and the `NO_REGISTRY` spy are three independent failure paths. |
| Posterior-varies precondition in the e2e world | The fixture accidentally produces a degenerate model, which would let scoring bugs hide behind a constant output. |
| No-holdout test | The builder calls `load_full_span` or the holdout manager: both are poisoned to raise. |
| No-accuracy test | Any log line or returned or metrics key mentions accuracy or score. |
| Discriminating e2e | weekly scores the whole row. Its precondition asserts that the pre-fix call raises on this fixture, so a revert turns the test red rather than passing vacuously. |
| Parity | The builder saves any column list other than `_cv_safe_active_features`'s. The preconditions prove that both exclusion rules fired, and the recorded all-columns mutation proves it bites. |
| No-skew | The serving model's posterior differs from `_refit_l2`'s by even one bit: different labels, embargo or columns. |
| NaN-names-it | The error does not name the column, date and latest complete month, or any state checkpoint was written before the failure. |
| Missing-artifact message | The message omits the command, or the command's module path no longer resolves (renamed module). |
| Same-month rerun | The band compounds on a re-run, or the belief double-counts the month. |
| `.gitignore` check | `nowcaster.pkl` can be staged by `git add data/`. |
| Ratchet and import AST check | `serving.py` imports a non-platform `trading_crab_lib` module. |
