<objective>
Put two questions in front of Glenn, with measured facts, BEFORE any code decides them. They concern
the trading surface, and nothing in any source artifact answers them.

Purpose: G-08-2 (UAT test 2, blocker). The approved fix direction says weekly.py scores the model's own
columns, and that a NaN in a model column must "fail loudly with a clear message (or apply the same
handling the backtest scoring path uses ... do not invent imputation)". Plan-time measurement (below)
shows that on today's tracked data **both of those options leave the report unusable**. The latest
live row, 2026-08-31, has no value in three of the model's columns. That is a publication lag, and it
is structural, not a glitch. Picking between failing, holding, or scoring an older complete month is
a choice about what Glenn trades from. It is not the planner's choice.

The measurement also surfaced a second fact nobody has seen. The serving nowcaster, fit by the
evaluated recipe exactly as the approved ruling requires, returns **one distinct posterior vector for
every complete month** from 2007-04-30 to 2026-06-30. The report would show the same regime
distribution every week. Recording that plainly, and deciding what the surface does about it, is the
honesty framework working as designed. Silently shipping it would be a check that can only confirm, at
the level of the product.

**Why this is its own plan.** The "split a checkpoint from implementation" rule, and the phase's own
precedent (08-05's A11 ruling came ahead of every number it could judge). It runs in wave 1, in
parallel with 08-11, so the ruling is ready before 08-14 needs it. This plan writes no production code,
so it has no tracer (precedent: 08-05, 08-09).

**What is NOT an option here.** Changing the serving recipe itself (a different feature rule,
imputation, dropping the lagging columns from the fit, or a different calibration) would produce a
configuration nobody evaluated. That is a new registry trial against a ledger at the ADR-0002 ceiling
(44/44, zero headroom), so it needs an ADR amendment and its own phase. It may be recorded as an open
item. It may not be chosen here.
</objective>
