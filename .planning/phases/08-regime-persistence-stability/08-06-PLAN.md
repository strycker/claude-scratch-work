<objective>
Build the recursion criterion 1 now asks for — an explicit Bayes filter with no feature column at
all — and build the guard that can prove it did not cheat.

Purpose: ROADMAP criterion 1, **reworded 2026-09-21** from *"the feature set includes the prior
predicted distribution"* to accept an explicit Bayes filter. The rewording is deliberate, not a
reinterpretation, and its reason is decisive: the L1 labeler is **non-causal within its window by
design** —

> *"The labeler is intentionally non-causal at the batch level: the DP jointly optimizes over the
> full time axis, so a label at month t is influenced by the global fit including months after t."*
> [`labeling/jump_model.py:15-18`, verbatim]

— so a **trained** prior-state column at training row *m* carries information from months after
*m−1*, all of it still inside `train_index` and strictly before the decision date *t*. **No
holdout boundary, no expanding-window guard, no purge and no embargo can detect that.** It is not
leakage across the decision date; it is leakage across the causality direction *within* the
training window, and this platform has no guard for that shape. Eliminating the channel beats
guarding it.

Output: `prediction/regime_filter.py`, a signed-offset extension to `evaluation/sojourn_lag.py`,
and the guard tests. **Wiring into the drivers is plan 08-08's** — deliberately, so the filter and
its guard are reviewable before either touches a decision path.

**What the filter is, exactly.** `A` is `prediction/transition_matrix.py::empirical_transition_matrix`
(already exists, already the v1 transition machinery) estimated from the step's own in-window L1
labels. `L_t(j)` is the nowcaster's calibrated posterior divided by the in-window class prior — a
Bayes inversion from a posterior back to a class-conditional likelihood ratio, so the class prior
is not counted twice. `pi_0` is the in-window unconditional occupancy. Cost: one matrix multiply
per step.

**The second catch, stated rather than glossed.** `A` estimated from the *smoothed* in-window
labels encodes a transition structure that was itself fitted non-causally within the window. That
is a weaker cousin of the teacher-forcing problem. It is defensible — those same in-window labels
are already the nowcaster's training target, so no new information class enters — but it is not
nothing, and it goes in the module docstring, not in a footnote.

**Four research pitfalls are structurally VOID under this design, and the plan says so to stop an
executor building guards against a surface that does not exist.** Because no feature column is
added: Pitfall 1 (`_cv_safe_active_features` at `driver.py:166` drops the newest-starting column
first, which a prior-state column would always be) cannot fire; Pitfall 3 (K prior-state columns
are exactly collinear) has nothing to be collinear; Pitfall 4 (a third concept named "embargo")
introduces nothing; and §2.5's whole CV-interaction analysis — the widened embargo, the
meaningless CV-accuracy rise, the calibration-fold mismatch — is moot, because
`PurgedEmbargoedKFold` never sees a recursive column. **Pitfall 6 stays live**: 100 of 588 steps
degrade under `l2` routing and dampen measured churn, and every number this machinery produces
must be quoted with its degraded count.
</objective>

    - `unconditional_belief(states, *, state_index)` -> pd.Series over `state_index`, the
      in-window class distribution, zero-filled for unseen states, summing to 1.0. **This is both
      the cold start and the class prior**, by the same call, because a cold-start rule that
      differs from the prior rule is a second rule to keep in step.
    - `likelihood_ratio(posterior, class_prior, *, state_index)` -> pd.Series:
      `posterior(j) / class_prior(j)`, with **1.0** — "no evidence either way" — for any state
      absent from `posterior.index`. Assigning 0.0 to an absent state would assert evidence
      against it, which the nowcaster never produced. Raises `ValueError` naming the state if
      `class_prior(j)` is 0 for a state that IS present in `posterior` — a state the window never
      saw cannot have produced a calibrated posterior, and that combination is a wiring bug.
    - `filter_step(prior_belief, transition_matrix, posterior, class_prior)` -> pd.Series:
      predict (`prior_belief @ A`) then update (elementwise by `likelihood_ratio`) then normalize.
      Raises if the pre-normalization mass is 0 rather than returning a NaN vector.
    - `predict_only_step(prior_belief, transition_matrix)` -> pd.Series: `prior_belief @ A`,
      normalized. **This is the missing-observation rule**, and it is a decision with a reason:
      on a degraded step there is no `L_t`, and holding `pi` unchanged would assert "the world did
      not move", which is a different and unwarranted claim. Advancing by the transition step
      alone is what a filter does when an observation is missing.
    - `transition_matrix_for(states, *, state_index)` -> a K x K frame with **every** state
      present as a row: `empirical_transition_matrix`'s output reindexed, with an absent 'from'
      row filled by the unconditional belief (the maximum-entropy choice consistent with the
      window) and a logged WARNING naming the state. Never filled with a uniform row and never
      left as NaN.

    Tests that must be able to fail:
    - **Sum-to-one.** After `filter_step`, the belief sums to 1.0 to 1e-12 across a 20-step
      synthetic sequence. Fails on a missing normalization.
    - **A sharp likelihood dominates a diffuse prior, and a diffuse likelihood does not move a
      sharp prior.** Two fixtures with the expected argmax named in each assertion. Fails if the
      predict and update steps are transposed or if one is dropped.
    - **The absent-class rule.** A posterior missing state 3 leaves state 3's belief equal to its
      pure prediction-step value, not zero. Assert the exact expected number. Fails if absent
      classes are zero-filled.
    - **Zero class prior with a present posterior raises**, naming the state.
    - **`predict_only_step` moves the belief.** On a non-identity `A`, assert the returned belief
      differs from the input by more than 1e-6 in at least one coordinate, and that repeated
      application converges toward `A`'s stationary distribution. Fails if the "missing
      observation" rule was implemented as a hold.
    - **Determinism and purity.** `filter_step` does not mutate any argument; two identical calls
      return equal Series.
  </behavior>

|----------|-------------|
