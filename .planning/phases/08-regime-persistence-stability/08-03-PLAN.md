<objective>
Build the machinery §4.4 criterion 3 needs, and build it so its two silent-failure modes are
tests rather than footnotes.

Purpose: `grep` for `hungarian|linear_sum_assignment|subsample_stab` across `src/` and `tests/`
returns **nothing**. Criterion 3 — *"re-estimate on subsamples; states persist with matched
emission parameters (match via Hungarian algorithm on distribution distances to defeat label
switching). A 'regime' that evaporates when 2008-09 is dropped is an episode, not a regime"* —
has never been run for either classifier, and it is the test that decides whether classifier #1's
states are regimes or episodes. This plan builds the module and its guards. Plan 08-07 runs it
and writes the verdict.

Output: `labeling/stability.py` and its test file. No artifact, no run, no record — those are
08-07's, deliberately, so the machinery is reviewable before it produces a number that will be
read as evidence.

**The measured basis for the distance choice, so it is not re-litigated at execution time.**
`08-RESEARCH.md` §5.2 benchmarked three candidates at this project's actual dimension (d=10) and
actual state sizes, 20 replications each. Signal-to-null separation at n=40: centroid distance
**1.70x**, Gaussian closed-form W2 **1.22x**, empirical multivariate Wasserstein **1.05x**.
`scipy.stats.wasserstein_distance_nd` is **rejected** — at n=40, d=10 its sampling bias (2.88) is
three times the true signal (0.949), the known `n^(-1/d)` convergence of empirical optimal
transport arriving exactly where this project lives. The jump model has **no emission
distribution**: it has centroids and squared-Euclidean distance to them
(`jump_model.py:179`), which is a spherical Gaussian with common variance. Centroid distance is
faithful to the model's own objective, has zero free parameters, and wins the benchmark at every
sample size that matters here. Use it as the primary. A Gaussian-W2 secondary is optional and,
if included, must be labelled secondary — it halves the separation ratio at n=40.

**No threshold is invented here, and none may be added later.** The design gives none,
deliberately. The module reports quantities; a human reads them. The one existing,
human-authorised pass/fail is §4.4's AMENDMENT condition (i) — *"it recurs in at least three
temporally separated episodes"* — and it binds only on the sub-floor state invoking the
recurrence exemption. Adding a persistence threshold after seeing the numbers is the tie-break
shape the pre-registration at `298b1bc` forbids elsewhere, and it would be no more honest here.

**Registry cost: zero.** Re-fitting the labeler on a subsample at the **pinned** (K, lambda) is a
diagnostic, not an evaluated configuration: nothing is being selected and no result may re-pin K
or lambda. The module never writes to the ledger and never reads a tunable it could sweep.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reference fit ↔ subsample fit | Two fits with independently-refit winsorization and scaling. The de-standardization is the only thing that makes their centroids comparable. |
| stability diagnostic ↔ the labeler | `stability.py` is a pure function of a fit. It must not modify `jump_model.py`, `label_regimes` or any pinned (K, lambda). |
| diagnostic ↔ selection | Re-fitting at the pinned (K, lambda) selects nothing. No stability result may re-pin K or lambda. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-12 | Spoofing | centroids compared across differently-standardized fits (Trap A) | **critical** | mitigate | `standardization_params` is pinned elementwise against `standardize_features`; the Trap A test asserts the de-standardized distance is correct AND that the naive standardized one is wrong, with the wrong value named. |
| T-08-13 | Spoofing | an evaporated state scoring *stable* on a frozen centroid (Trap B) | **critical** | mitigate | Every row carries subsample occupancy; `evaporated` is set from occupancy alone and is constructed before any verdict field; a test asserts distance ~0 AND `evaporated is True` on a zero-occupancy fixture; a WARNING is logged per evaporated state. |

| T-08-15 | Repudiation | a matched distance read without its n-matched null | high | mitigate | `split_half_null` is computed per state at the subsample's own n and is a required field of `stability_row`; the synthetic 0.706 benchmark is not hard-coded anywhere. |
