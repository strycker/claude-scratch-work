## Honest-evidence note: how each new check can fail

| Check | Fails when |
|---|---|
| driver discriminating | `run_backtest` divides by anything but the prior its step's fit returned (M1). |
| joint discriminating | A classifier divides by the window prior or the other classifier's prior (M2); precondition: the priors differ at some step. |
| cold-start re-derivations | The cold start moves off `unconditional_belief` (M3). |
| l1only pin (unmodified) | The filter reaches the decision-bearing leg (M4). |
| serve/backtest prior parity | The persisted prior differs from `_refit_l2`'s by one bit. |
| refusal arms | The whole-window shape or a non-normalized prior is accepted, or silently renormalized (M5 to M7). |
| no-evidence arm | A posterior equal to the training prior moves the belief off normalize(π A). |
