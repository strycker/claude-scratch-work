## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest `>=8.0` |
| **Config file** | the app `pyproject.toml` `[tool.pytest.ini_options]` (`testpaths = ["tests"]`, markers `realdata` and `network`, `filterwarnings = ["error::FutureWarning"]`); none exists yet, so Wave 0 creates it |
| **Quick run command** | `pytest tests -q -p no:cacheprovider -x` plus `ruff check src tests` |
| **Full suite command** | `pytest tests -q -p no:cacheprovider && ruff check src tests && python -m build . --outdir dist-app && python -m build src/trading_crab_lib --outdir dist-lib && bash scripts/check_wheels.sh dist-lib dist-app` |
| **Estimated runtime** | ~30 seconds for the suite (offline, synthetic data); ~60 seconds with both builds and the wheel check |

---

## Sampling Rate

- **After every task commit:** the quick run command.
- **After every plan (commit group):** the full suite command, then push the branch and confirm CI (Python 3.10 with
  pandas 2, Python 3.13 with pandas 3).
- **Before `/gsd-verify-work`:** full suite green locally and in CI, plus Glenn's Mac real-data gate recorded.
- **Max feedback latency:** ~60 seconds.
