### `platform/code_version.py` (utility)
**Analog:** REF `code_version.py:1-57`. Rewrite to ~30 lines; keep the behaviour, not the prose.
**Keep:** git runs in the module's own directory (`cwd=_HERE`), so an editable install of another clone names the right checkout; 5 s timeout; None on failure; detached HEAD text; "not a git checkout" fallback line.
```python
def _git(*args, cwd=None):
    try:
        done = subprocess.run(["git", *args], cwd=cwd or _HERE, capture_output=True, text=True, timeout=5)
    except (OSError, subprocess.SubprocessError, UnicodeDecodeError):
        return None
    return done.stdout.strip() if done.returncode == 0 else None
# final line format: f"Code: {branch} @ {sha}{dirty} — {root or _HERE}"
```
**Do NOT carry:** the `git ls-files --error-unmatch` "installed copy" check and `_CODE_PATHS` dirty-scan across submodules (lines 22-24, 45-56) unless a test needs them; keep "+ uncommitted changes" only if it stays under ~5 lines. ### `platform/ingest.py` (service, external-API batch)
**Analogs:** REF `ingestion/tiingo.py` (fetch + parse), `ingestion/macro_monthly.py:71-150` (FRED monthly), `ingestion/publication_lags.py:120-140` (lag apply). Three functions + `build()`, ~170 lines. Plain `requests`, no `fredapi`, no `curl_cffi`, no `http_get/HTTP_ERRORS` wrapper.
**Keep (edge cases):**
1. **Tiingo request/headers** (tiingo.py:46,47,170,189-199): base `https://api.tiingo.com/tiingo/daily`, URL `f"{base}/{ticker}/prices?{urlencode({'startDate':..,'endDate':..})}"`, key ONLY in `Authorization: Token <key>` header, never in the URL. Retry 429 only, 3 tries, backoff `1.0 * 2**attempt`, 1 s between tickers.
2. **Tiingo parse** (tiingo.py:96-150): prefer `adjClose`, fall back to `close` per row; tz-naive normalized daily index; sort, drop duplicate dates (`keep="last"`), `dropna`; empty -> None (skeleton: empty -> `SourceError`).
```python
index = pd.to_datetime(dates, utc=True).tz_localize(None).normalize()
series = pd.Series(values, index=index, name=ticker, dtype=float).sort_index()
series = series[~series.index.duplicated(keep="last")].dropna()
```
3. **Redact keys from exception text** (tiingo.py:59-70): `text.replace(api_key, "***")`; FRED's key travels in the URL query so `requests` exception strings contain it. Apply to every raised/logged exception.
4. **FRED:** `"."` is a missing observation (parse `value` with `pd.to_numeric(..., errors="coerce")`; test fixture must contain one). Dates are the 1st of the month; convert with `index.to_period("M").to_timestamp("M")` (RESEARCH). Reference (macro_monthly.py:71-87) resamples with `resample("ME").last()`, which is wrong-by-default for first-of-month stamps only if not resampled; either is fine, pick one and test it.
5. **Month-end prices:** `daily.resample("ME").last()` (reference `prices_daily.py:366`); then drop labels not strictly before today (incomplete month).
6. **Lag apply** (publication_lags.py:120-134): unlisted column raises `ValueError`; shift by timestamp so gaps are safe:
```python
shifted = {c: frame[c].shift(table[c], freq="ME") if table[c] else frame[c].copy() for c in frame.columns}
out = pd.concat(shifted, axis=1, sort=True)
```
7. **Fail loud** (Pattern 2): fetch everything, collect failures, raise one `BuildFailed` before any write. The reference returns None per source and logs a warning (tiingo.py:175-202 "never abort the batch"), which is exactly the behaviour D-08 reverses.
**Do NOT carry:** `--allow-missing`, ALFRED/vintages (`alfred.py`), multpl/macrotrends/World Bank scrapers, splice logic (`splice.py`, 612 lines), thread-pool fetch, session objects, `base_url` and `max_retries` parameters, the `lagged`/`not_lag` derived-vs-vintage checks (publication_lags.py:~124-130), `publication_lags.json` marker file (use the meta sidecar), `fred_`-prefixed names (columns are `gs10 tb3ms baa unrate SPY TLT IAU USO`).
