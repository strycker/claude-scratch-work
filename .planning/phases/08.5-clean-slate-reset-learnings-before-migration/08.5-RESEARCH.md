## Q2. `realdata` marker mechanics

- Markers live in `pyproject.toml` `[tool.pytest.ini_options]`, l.52-55: `markers = [` with the entries
  `"real_browser: ..."` and `"network: ..."`. There is no `--strict-markers`, but register the new one anyway to avoid

- `tests/conftest.py` has only `pytest_report_header` today (l.23); no `pytest_collection_modifyitems`. Add (about 12 lines):

```python
_BUILT_DATA = Path(__file__).resolve().parents[1] / "data" / "checkpoints" / "platform" / "monthly_raw.parquet"

def pytest_collection_modifyitems(config, items):
    if _BUILT_DATA.exists():
        return
    if "realdata" in (config.getoption("-m") or ""):
        raise pytest.UsageError("-m realdata needs built data: run `python scripts/build_platform_data.py` first")
    skip = pytest.mark.skip(reason="no built data under data/: run `python scripts/build_platform_data.py`")
    for item in items:
        if "realdata" in item.keywords:
            item.add_marker(skip)
```
  Path check: `platform/checkpoints.py:29` `PLATFORM_CHECKPOINT_DIR = DATA_DIR / "checkpoints" / "platform"` and the spine test's
  `_RAW = _CKPT / "monthly_raw.parquet"` (l.38-39). The `UsageError` branch is a recommendation (Claude's discretion): without
