## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 9.x (config `pyproject.toml` `[tool.pytest.ini_options]`) |
| **Config file** | `pyproject.toml` (markers ~l.52); `tests/conftest.py` |
| **Quick run command** | `.venv/bin/python -m pytest <touched test file> -q -p no:cacheprovider && ruff check src/ tests/` |
| **Full suite command** | `.venv/bin/python -m pytest tests/ -q -p no:cacheprovider` (plus the same on a Python 3.10 + pandas 2 venv) |
| **No-data run** | `S=$(mktemp -d); trap 'rm -rf data outputs; mv "$S/data" data; mv "$S/outputs" outputs' EXIT; mv data "$S/data"; mv outputs "$S/outputs"; .venv/bin/python -m pytest tests/ -q -p no:cacheprovider -rfEs` (plan 1 only, while data is still tracked) |
| **Estimated runtime** | ~300–480 seconds full suite |

---

## Sampling Rate

- **After every task commit:** the quick run command on the touched test files, plus `ruff check src/ tests/`.
- **After every plan:** the full suite on pandas 3 and pandas 2; for plan 1 also the no-data run.
- **Before `/gsd-verify-work`:** full suite green on both environments; plan 2's fresh-clone run green.
- **Max feedback latency:** ~60 seconds per task (targeted files), ~8 minutes per plan.
