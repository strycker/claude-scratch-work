## Commands (as the CLI prints them)

```
archive NAME [--note TEXT]   archived NAME -> archives/NAME (x.x MB)
list                         <name> <created> <MB> promoted=yes|no <commit> trials=<n> <note>
reset [NAME] --yes           deleted pickle (never archived): <path> ...
                             reset done; everything else is in archive auto-YYYYMMDD-HHMMSS. Undo: ... restore <that name>
reset (no --yes)             reset would empty <data> and <outputs> (after archiving them); re-run with --yes   (exit 1, nothing changed)
restore NAME                 restored N files from NAME   [warning: archive was made at commit X, HEAD is Y]
                             regime_tilt users only: no model is restored; refit with `python -m trading_crab_lib.platform.report.serving`
promote NAME                 promoted NAME: committed and tagged model/NAME. Not pushed; to publish: git push origin model/NAME
```

Refusals print `refused: <reason>` and return 1. None of these was run against the real repo trees; only tmp_path worlds and a throwaway git repo.

## Safety properties (threat model T-08.4-05..10)

- restore: `tarfile` `filter="data"` (refuses when `data_filter` is missing), staging dir, members must be regular files with safe `data/` or `outputs/` paths, no pickle suffix, and the (name, size) set must equal the manifest; every sha256 is checked before anything moves.
- reset: `--yes` only; archives first and re-reads the written archive; refuses if `archives/` or the registry lies inside a tree; only file contents are deleted (`.gitkeep` kept).
- promote: refuses a dirty tracked tree, a missing local archive, an existing promoted name and over 50 MB; drops the G-11 stems and `weekly_report.md` (listed in the manifest's `excluded`); unstages and deletes the folder if add or commit fails; never pushes.
