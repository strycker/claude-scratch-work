## How to run these safely (Glenn's Mac)

All four checks run in a throwaway folder through the path overrides, so the repo's tracked
`data/` and `outputs/` are never touched. Local archives land in the repo's `archives/`, which is
gitignored. From the repo root, on the 8.4 branch after `git pull`:

    export TC_DATA_DIR=$HOME/tc-cold/data TC_OUTPUT_DIR=$HOME/tc-cold/outputs

Undo at the end:

    unset TC_DATA_DIR TC_OUTPUT_DIR
    rm -rf $HOME/tc-cold $HOME/page-before.md archives/smoke-0804 archives/auto-*
