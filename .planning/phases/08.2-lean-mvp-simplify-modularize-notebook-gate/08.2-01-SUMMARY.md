# Phase 8.2 Plan 01: Weekly Page on the No-Regime Core Mix Summary

The weekly page now trades the measured no-regime ablation leg. It uses a constant one-state belief, `returns_by_regime_stats` over returns up to the scored month, the same `vol_targeted_tilt` and the 5 pp band. The regime sections collapse into one suspended block. The mode is persisted, so a switch trades the new target in full and says so (A-15). Parity with the driver holds at rel 1e-9 on synthetic data and on tracked data.
