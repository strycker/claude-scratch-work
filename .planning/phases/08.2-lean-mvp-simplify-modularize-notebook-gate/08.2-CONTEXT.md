<decisions>
## Implementation Decisions

### Trial budget (ADR-0004)
- **Opening count:** `total_trial_count()` = **46**, read live 2026-10-01T17:34Z.
- **Budget: 0 rows.**
  - The notebooks and the page read **tracked** outputs: `outputs/reports/platform/backtest_*` and `pit_08.1/before/*`.
  - Any refit (serving) uses `NO_REGISTRY`.
  - Tests append nothing.
- **Phase ceiling: 46.**

### Allocation (what Glenn trades from)
- **D-01: Core mix = the measured no-regime ablation path.**
  - It is the vol-targeted SPY/TLT/IAU/USO/cash mix that `run_backtest(use_regime_tilt=False)` computes, using the same
    functions: a constant one-state belief, `vol_targeted_tilt`, then `execute_rebalance` with the 5 pp no-trade band.
  - It is the leg 8.1 measured: TLW 4.0424, MDD −19.83%. The weekly target must equal what that leg would hold.
  - Selected by config (e.g. `report.allocation_mode: no_regime`, the default). The `regime_tilt` mode stays available
    but is **not** the default, per DECISIONS G-06.
  - **Reversibility:** cheap, a config switch.
- **D-02: E-07 stays deferred.** No change to how returns are built. The page and N7 print the caveat in one line:
  scoreboard returns use monthly-average prices for equities, oil and long duration, which may flatter trend and tilt
  rules. Fixing it is the first item of the regime-rebuild phase.

### Weekly page (behavior)
- **D-03: Regime view suspended.**
  - The page shows a status line instead of probabilities, belief or posture: "Regime view: suspended — the served
    nowcaster is input-independent (fixed in the regime rebuild); the allocation does not use it."
  - Serving may still compute the belief. The page simply does not present it.
- **D-04: Tripwire section.**
  - Run the existing `tripwire/monitor.py::run_tripwire`, which has three signals: realized-vol spike, credit-spread
    velocity, and SPY drawdown from peak.
  - Print each signal red or green, plus the escalation level.
  - **Advisory only:** it does not change weights.
  - It must not impute, and it must say which date each signal is computed as of.
- **D-05: Static scoreboard.**
  - One table read from the tracked backtest outputs of the last budgeted run, which is 8.1's D-04 run.
  - Columns: strategy (regime tilt), no-regime ablation, SPY, 60/40, Faber. Each with terminal log wealth and max
    drawdown, plus the run date and window, and the E-07 caveat line.
  - No weekly recompute. It changes only when a budgeted run rewrites those outputs.

### Simplify and modularize
- **D-06: Park, don't delete.**
  - Move `labeling/classifier2.py`, `backtest/joint_driver.py` and `labeling/stability.py` out of the active path, for
    example into a `platform/parked/` subpackage, along with any helpers only they use. The method is the planner's choice.
  - The weekly and serving import graph must not reach parked code. Add a test that fails if it does.
  - Every test, script and notebook that references them keeps working, with updated imports. That is about 32 files.
  - The Phase 7/8 record tests must stay green **unedited in their assertions**: only import paths may change.
  - **Reversibility:** cheap.
- **D-07: Module map document.**
  - `platform_design/MODULE-MAP.md` (or a section of the rebuild guide) lists M0–M7 with each module's interface
    (in → out), its current files, its notebook, and its gate.
  - Parked modules are listed as M9+ or parked.
  - Docs only: no code moves beyond D-06.

### Notebook gates
- **D-08: N4, serving and weekly report.**
  - Builds or loads the serving artifacts, runs the weekly assembly in a scratch output directory, and shows the page.
  - Asserts that two runs give an identical page, and shows the as-of date and staleness.
  - One sign-off cell.
- **D-09: N6, filtered belief.**
  - Plots the backtest's filtered state probabilities from `backtest_filtered_state_probs.parquet`, which has 499
    distinct rows over 502 steps.
  - Puts that next to the served (constant) belief, so the reason for D-03 is visible.
  - One sign-off cell.
- **D-10: N7, does the regime layer pay rent?**
  - States the question, then shows the before|after point-in-time table (E-06) and the equity curves of tilt, ablation,
    SPY, 60/40 and Faber from tracked outputs.
  - Shows the DSR line against the hurdle at the live count, and the E-07 caveat.
  - Answers in one sentence: "No — the regime view stays advisory (G-06)."
  - One sign-off cell.
- All three notebooks:
  - live in `notebooks/platform/` next to P1–P6;
  - call plotting helpers in `platform/plotting/`, with no inline plotting logic (G-02);
  - run with `nbconvert --execute` on real data in CI-free local checks.

- Notebook names, e.g. `P7_serving_report.ipynb`, `P8_filtered_belief.ipynb`, `P9_does_regime_pay.ipynb`, or N4/N6/N7.

## Existing Code Insights

### Reusable assets
- **No-regime allocation.** It already exists as the tilt-off branch of `run_backtest`: constant `{0: 1.0}` belief,
  `states = 0` over the training window, and `returns_by_regime` taken unconditionally. Weekly can reuse the same
  functions. No new allocation math is allowed (D-02 of Phase 5: the ablation is the same code path).
- **Tripwire.** `run_tripwire` and `escalate` already exist and are tested. They have never been wired into the page.
- **Tracked outputs** for the scoreboard and N6/N7:
  - `backtest_kpi_table.parquet`;
  - `backtest_equity_curve_{strategy,ablation}.parquet`;
  - `backtest_filtered_state_probs.parquet`;
  - `pit_08.1/before/*`.

### Established patterns
- Weekly uses load-before-save for its state (belief, active regime, executed weights), and same-month re-runs are
  idempotent (08-16 and 08.1-02 tests).
- Floats are compared at rel 1e-9, abs 0. Config drives behavior, with no hardcoded series metadata.

### Integration points
- The weekly and serving import graph touches the parked modules only in docstrings, so parking does not change
  runtime imports on the weekly path.
- About 32 test, script and notebook files reference the parked modules.
