Complete the L1 labeler around the Plan 03-01 core: label/confidence persistence (L1-02), the
label-churn monitoring metric (L1-03, design §5.4), the §4.4 report-only occupancy/sojourn

load-before-save ordering are the subtle correctness concerns (Pitfall 3): first run must
report NaN, a repeat run must report 0.0, and the previous checkpoint must be read before the
new one overwrites it. The §4.4 criteria are report-only in v1 (D-02) — the labeler always
completes; violations are logged, never raised.

Output: `diagnostics.py` (5 functions incl. orchestration), the churn/occupancy/profile/
persistence test classes, and the persisted regime checkpoints + diagnostics artifact.
