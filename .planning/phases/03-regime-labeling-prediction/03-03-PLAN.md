<objective>
Build the L2 calibrated nowcaster (L2-01, design §5.1, §14 Phase 1) in a self-contained
`platform/prediction/nowcaster.py`: the structural 12-month label embargo (D-01/L1-02), a
`CalibratedClassifierCV`-wrapped multinomial `LogisticRegression` fit through Phase 2's
`PurgedEmbargoedKFold`, the transition-window accuracy headline metric, and one-trial
registry logging.

Purpose: The nowcaster is the only strictly-causal model in this phase, and it carries the
two highest-severity honesty threats: look-ahead leakage through fresh trailing labels
(mitigated by a *structural* embargo, not advisory) and unregistered evaluation (mitigated by
mandatory registry logging). Overall accuracy alone is the design's named trap (~90% from
persistence), so transition-window accuracy is reported alongside it, never instead of it.

Output: `nowcaster.py` (4 functions), the prediction package init, and the nowcaster test
file seeded with the embargo invariant, calibrated-output, transition-window, and registry
tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| labeler labels → nowcaster training targets | Fresh trailing labels are revision-prone; crossing this boundary without an embargo is look-ahead leakage |
| nowcaster evaluation → trial registry | Every evaluated configuration must be recorded (multiple-testing denominator at design freeze) |
| persisted joblib model artifact → future load | Deserialization executes code; only load own-provenance artifacts |

| T-03-04 | Information Disclosure | build_nowcaster_training_set | high | mitigate | Structural 12-month embargo (D-01) applied ONCE when building (X,y); the trailing 12 months are physically absent from y, proven by a real-output assertion (TestEmbargoInvariant). Blocks on this threat. |
| T-03-05 | Repudiation | evaluate_nowcaster registry logging | high | mitigate | Exactly one trial row logged per evaluation via run_walkforward's automatic append_trial (or direct append_trial fallback); TestRegistryLoggingOne asserts the +1 delta. Blocks on this threat. |
| T-03-06 | Tampering | joblib model artifact | medium | mitigate | Persist via joblib.dump, never raw pickle (P27/D14); never load an artifact of unknown provenance |
| T-03-07 | Denial of Service | build_nowcaster_training_set | low | mitigate | embargo_months < 0 raises ValueError before slicing (Security Domain V5), preventing a silent empty/inverted training set |
