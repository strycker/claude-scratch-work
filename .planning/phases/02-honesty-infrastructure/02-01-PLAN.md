<objective>
Install the physical 2021+ holdout carve (HON-01, design §8.5 / D13) and lay the
`platform/honesty/` package foundation the rest of the phase builds on. This plan owns the
one shared config file (`config/platform_settings.yaml`) — it adds the `holdout:`,
`registry:`, and `cv:` sections in a single edit so that Plans 02–05 read them without ever
re-touching the file — and creates the empty `honesty/__init__.py` package marker every later
module imports through.

Purpose: development must be structurally unable to see 2021+ data. The carve is an
ingestion-level file split (D-03): the dev checkpoint tree physically ends at 2020-12-31, and
2021+ rows live only under `data/holdout/`, which the default code path never reads.

Output: config sections; `honesty/` package; `holdout.py` (split + two checkpoint-manager
factories + a loud boundary guard); an invariant test proving the default loader CANNOT
return post-2020 rows.
</objective>
