<objective>
Build the walk-forward runner (HON-03, design §8.1 / §14 Phase 0 exit): an expanding-window
loop that refits a model on data <= t at each step, records the decision, steps forward, and —
per D-02 and RESEARCH Pitfall 3 — automatically logs the full evaluated configuration to the
trial registry when the run completes. It executes a TRIVIAL model
(`DummyClassifier(strategy="prior")`, ponytail rung 5: sklearn already implements "predict the
prior/most-frequent class") end-to-end, proving the refit -> record -> step-forward cycle. Real
models (jump-model labeler, nowcaster) arrive in Phase 3 against this same interface.

Purpose: the Phase-0 exit criterion — a walk-forward runner that runs a trivial model end to
end and records what it decided, with every configuration captured in the ledger automatically.

Output: `walkforward.py` (expanding_steps generator + run_walkforward) and a synthetic,
no-network test proving refit-on-data-before-t at every step and exactly one registry trial
logged per run.
</objective>
