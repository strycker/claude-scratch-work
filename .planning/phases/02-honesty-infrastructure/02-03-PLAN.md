<objective>
Hand-roll `PurgedEmbargoedKFold` (HON-04, design §6.5 / R7, López de Prado ch. 7): a
sklearn-compatible cross-validator that purges training rows whose label window overlaps a
test fold and embargoes a further window immediately after it. This is the ONE piece of the
phase with genuine design risk — the free ecosystem has no maintained implementation
(mlfinlab relicensed closed-source; timeseriescv unmaintained/SUS, RESEARCH Package Legitimacy
Audit) — so it is hand-rolled and CORRECTNESS-CRITICAL. plain `TimeSeriesSplit(gap=N)` is
insufficient (single fixed gap, not label-aware purge + separate embargo).

Purpose: any Phase 3+ supervised component with overlapping labels (forward-return /
forward-transition targets) gets a leakage-safe CV as a drop-in `cv=` replacement.

Output: `cv.py` (the BaseCrossValidator subclass) and a property-style test suite that proves,
for every fold, that no train index sits inside the purge-or-embargo window of any test index.
</objective>
