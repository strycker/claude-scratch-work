**Missing helper, `equities_tr`.** HEAD's `equities_tr` does not equal a rebuild from its own unlagged inputs: it sits on a merge-preserved base (1790.04 at 1962-01, where the rebuild gives 1.0). The helper therefore:
- requires HEAD = unlagged rebuild × one constant k, with an identical NaN mask. The measured ratio is constant to 4.9e-15; otherwise the script refuses;
- returns the lagged rebuild × k.

Consumers read only returns (`pct_change`), so this equals a fresh build's returns while keeping HEAD's level base.
