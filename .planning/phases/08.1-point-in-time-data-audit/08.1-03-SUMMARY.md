## Migration (Task 1b)

**The script I found was incomplete.** The previous executor's `scripts/migrate_publication_lags.py` called `_rebuild_lagged_level`, which it never defined, so it would have crashed with a NameError. I checked the rest against the plan and it was correct: merge=False plus the marker; it refuses a second run; it checks row equality at 2026-08-31 before saving; pre-vintage GDP equals HEAD two month-ends earlier; any other drift keeps the HEAD value and is logged. I wrote the missing helper.

**The missing helper, `equities_tr`.** HEAD's `equities_tr` does not equal a rebuild from its own unlagged inputs. It sits on a merge-preserved base (1790.04 at 1962-01, where the rebuild gives 1.0). The helper therefore:
- requires HEAD to equal the unlagged rebuild × one constant k, with an identical NaN mask (the measured ratio is constant to 4.9e-15; otherwise the script refuses);
- returns the lagged rebuild × k.

Consumers read only returns (`pct_change`), so this equals a fresh build's returns while keeping HEAD's level base.
