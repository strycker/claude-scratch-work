<objective>
Measure criterion 7: does adding classifier #2 help, walk-forward, and does it survive
deflation for the number of trials this project has actually run.

Purpose: this is the criterion most exposed to the failure `UAT-AUDIT-2026-09-09` documents — a
lift number that passes as phrased while resting on a window nobody stated, or a Sharpe that
looks good because the multiple-testing denominator was undercounted by 38. Both failure modes
are addressed structurally here: the #1-alone baseline is produced by the *same* harness as the
joint leg with the blend weight set to 1.0, so the two legs cannot silently diverge in window
or cost model; and the deflation denominator is read live from the provenance header rather
than from any figure written down in a planning document.

<assumption_delta_decision>
**Noun now primary:** the *regime labeling pair* — classifier #1 (crisis/stress axis) plus
classifier #2 (leadership/relative axis) — replaces "the regime labeler".

**Decision: `add-alongside`** (the checkpoint's default is `promote`; this is reasoned).

**Rationale:** D-14 locks two separate probability inputs with no product state space.
Classifier #1 remains the sole L1 labeler consumed by L2, by `report.py`'s smoothed reference
and by §5.4; #2 enters only at the L4 blend.

**Relevance to this plan specifically:** `add-alongside` is exactly what makes criterion 7's
comparison expressible as a single parameter. Because classifier #2 is blended in rather than
substituted for #1, the #1-alone baseline is the same harness at `blend_weight_1` of 1.0 — a
one-parameter ablation. Under a promote design the baseline would be a different code path and
the comparison would carry every difference between the two paths as confound.

**What would later force a promote:** the results this plan produces — low dependence from plan
07-09, positive lift on both axes inside the bands plan 07-10 confirmed, and a DSR clearing
0.5. If all three land, the fixed blend weight stops being a defensible constant and a
promote-or-product design earns its own ADR. If they do not, `add-alongside` was the right call
and the record says why.
</assumption_delta_decision>
