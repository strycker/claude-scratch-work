<objective>
Recompute the dev `monthly_features` checkpoint from the cached `monthly_raw` checkpoint, lock
the TEN-column frozen set, and re-pin the golden A13 regression constant — all in one commit,
after preserving the pre-fix evidence.

Purpose: **D-02-A** supersedes D-02. D-02's "the frozen set is 9" was measured against a stale
checkpoint. `compute_lean_features` assigns `features["oil"] = monthly_raw["oil"]` — an
unwindowed passthrough — yet on-disk `monthly_features.oil` starts 1985-02 while
`monthly_raw.oil` is fully populated from 1962-01. Oil's late start in features is a
rebuild artifact, not a data limit. Phase 7 exists to decide what the labeler is allowed to
see; locking a set that is wrong by accident would undermine the phase, and certifying numbers
against stale evidence is precisely the failure mode `UAT-AUDIT-2026-09-09` documents.

Output: a narrow offline recompute script, a corrected dev checkpoint, a preserved pre-fix
evidence record, and a re-pinned A13 golden constant.

**Requirement coverage.** REG-01 **in part** (the driver/reference feature-policy clause — this
plan supplies the data the policy is frozen over). **INV-01 is not claimed**: it is wave-2
invariant-candidate work, deferred by **D-09**.
