There are three P&L-only month-end raw columns (`sp500_close_me`, `dgs10_me`, `wti_me`, all lag 0) and one shared feature assembly that drops them. ## Deviations from Plan

1. **[Rule 1, test strength] The V3 fixture was too weak.**
   - **Problem:** the first synthetic P&L frame was an affine transform of `asset_returns`, so routing it into `returns_by_regime_stats` left the weights unchanged. The mutation stayed green.
   - **Fix:** the fixture now uses seeded N(0, 0.05) noise plus a negated USO column. The mutation then went red. This is in commit `1e7f819`.
2. **[Rule 2] Two safety guards added in `pnl_splice_cfg` / `pnl_only_columns`** (Task 1, `cf98fa2):
   - overlaid classes are forced to `optional: False`, and a list-valued overlay source raises. This turns pitfall 5 (silent fallback to an average) into an enforced rule rather than a convention.
   - `pnl_only_columns` raises if a `pnl_only` flag names a column the feature-side splice reads, because dropping it would change the features.
3. **The `cost` column is compared at rel 1e-9 / abs 0, not bit-exact.** `cost` = gross − (gross − turnover·bps), and the subtraction rounds differently for different gross returns. turnover, scale, active_regime and degraded are compared exactly.
4. **Process.**
   - **Tracer gate:** `workflow.auto_advance` is false, but Glenn's instruction was to run all tasks end to end, so I ran the tracer gate autonomously. I re-ran the Task 1 verify (102 passed) instead of stopping at a human-verify checkpoint.
   - **RED commits:** for each task the RED tests were written and seen failing before the implementation (Task 1: `AttributeError pnl_only_columns`; Task 2: the live-config test; Task 3: 4 wiring tests). Each task was then committed once, per the per-task commit instruction, with no separate `test(...)` commit.
   - **Behavior tests that passed on first run:** Task 2's behavior tests (oil, averaged series, gap) passed straight away against Task 1's generic builder. Only their config assertion was red. Their ability to fail rests on mutation proofs 3 and 4 above.
5. **Not done here, by instruction:** STATE.md and ROADMAP.md were not edited, nothing was pushed, and no `windows append`.
