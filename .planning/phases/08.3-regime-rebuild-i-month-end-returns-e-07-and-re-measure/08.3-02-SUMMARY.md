## Glenn's Mac pull instructions

Your Mac has uncommitted refreshed data in tracked checkpoint files from the 8.2 build. This branch changes the
tracked `monthly_raw` (47 → 50 columns), so git will refuse the pull until those local changes are set aside.

1. See them: `git status --short data/`
2. Then choose one:
   - **Discard (default).** Use this when the refresh is only a rebuild that the build re-fetches anyway:
     ```bash
     git checkout -- data/checkpoints/platform
     git pull
     ```
     If `git status --short data/` also lists files outside `data/checkpoints/platform`, run
     `git checkout -- data/` instead.
   - **Keep a copy.** Use this when it holds something to compare or reuse, such as a newer month:
     ```bash
     git stash push -m "pre-08.3 local data" -- data/checkpoints/platform
     git pull
     ```
     **Never `git stash pop` it.** It would restore a `monthly_raw` without the 3 month-end columns and conflict.
     Inspect it with `git stash show --stat stash@{0}`, take single files with
     `git checkout stash@{0} -- <file>`, then `git stash drop stash@{0}`.
   - **Never use `git reset --hard`.**
3. Then:
   1. `python scripts/build_platform_data.py`. The publication-lag marker matches the live table, and the build
      fetches `^GSPC`, DGS10 and DCOILWTICO.
   2. Serving.
   3. The weekly report.
   4. `pytest tests/ -q`.
