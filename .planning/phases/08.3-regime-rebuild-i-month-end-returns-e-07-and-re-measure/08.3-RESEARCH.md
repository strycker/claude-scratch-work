## Summary
The before run **reproduces the tracked 8.1 KPI table exactly** (rel diff 0.0 on all 10 numbers; both equity curves equal at rel 1e-9; 230 s, pandas 3.0.5 / Py 3.11). The registry sha was unchanged.

The E-07 leak is large. - **The one place.** `build_pnl_research_series(raw, cfg)`:
  - it overlays `cfg["pnl_splice"][cls]` onto `cfg["splice"][cls]` and calls `build_core_research_series`;
  - when the block is absent it returns the feature series, so synthetic test configs stay byte-identical. This follows the A-13 ruling-A2 pattern; a test pins that the live config has the block.
- **Wiring.** Its returns, through `tradable_asset_returns`, become the `pnl_returns=` kwarg of `run_backtest` (default `None` = `asset_returns`, so every existing caller is byte-identical).
  - `no_regime_ablation` passes it through, so both legs use the identical series.
  - Assert that `pnl_returns` has the same columns and covers every test date.
- **`returns_by_regime` counts as a model input, so keep it on the current series.** Three reasons:
  - (a) E-08's own rationale is "without mixing a measurement fix with a model change". Switching it changes weights, so before→after would no longer isolate measurement.
  - (b) Serving builds the weekly tilt from the same average series (`serving.py:196`). The backtest must measure the rule as served, which is the train/serve-skew rule `fit_l2_nowcaster` exists for.
  - (c) The average return for month t is fully known at t, so it is point-in-time as an *input*.
  - Flag for DECISIONS: averaging understates vol (σ falls by 17% for equities and 13% for long duration), so the vol target runs hot on the earned P&L. Moving the inputs is a later model change.
- **Faber:** use the month-end TR level for **both** its signal and its returns. That is canonical Faber and is how a switched core would be traded. This must be fixed in the plan *before* the run, because it affects D-03.
- **Proof of split.** Add a feature-neutrality test with 3 asserts:
  - (i) on real data, `rebuild_monthly_features(migrated monthly_raw)` equals the tracked `monthly_features.parquet` with `check_exact=True` (verified that this holds today on HEAD: 708×55 exact). Also check holdout rows against `data/holdout/`;
  - (ii) a synthetic `build_monthly_spine` run with and without the `_me` columns in the mocked macro frame gives frame-equal features;
  - (iii) the equity curves before and after the change have identical `turnover`, `scale`, `active_regime`, `cost` and `degraded` columns; only `return` moves.
  - Do **not** rely on file sha alone, which is trivially true if nothing is written.

| Asset (1972–2020, n=588) | corr | Δ mean (ann.) | vol old → new (ann.) | lag-1 autocorr old → new | corr(old_{t+1}, new_t) |
|---|---|---|---|---|---|
| equities_tr | 0.672 | +0.33 pp | 12.67% → 15.24% | 0.231 → 0.022 | **0.547** |

  - load tracked `monthly_raw` (776×47, 1962-01..2026-08);
  - fetch the 3 columns and `reindex(existing.index)`. **Never add rows**, because new rows would pad every existing column;
  - append them after the existing columns;
  - assert `pd.testing.assert_frame_equal(new[existing.columns], existing, check_exact=True)` plus identical index and column-order prefix;
  - `cm.save(new, "monthly_raw", merge=False)`. `merge=True` would reorder columns: new first (`checkpoints.py` `ordered_cols`);

  - leave `monthly_features`, holdout, labels and `splice_provenance.json` untouched.

## Common Pitfalls
1. **New raw columns leak into L2.** `monthly_features = concat([monthly_raw, lean])` (`transforms_monthly.py:441`, duplicated in `scripts/recompute_monthly_features.py:53-76`), and L2 fits on every column. Extract one `features_from_raw()` that drops `pnl_only_columns(cfg)` (`pnl_splice` sources minus `splice` sources) and is used by both. Warning sign: a nowcaster `feature_names_in_` containing `_me`.
2. **Editing `splice.oil` instead of overriding it** changes features and breaks the oil-provenance tests.
3. **The marker mismatch after adding lag entries** blocks Glenn's next build (8.1 Pitfall 1 family).
4. **`merge=True` in the migration** reorders columns. **Adding rows** breaks byte-identity.
5. **A silent fallback to the average series in P&L.** List only the `_me` column per class, with no chain, so the preflight raises.
6. **Glenn's Mac** has uncommitted checkpoint edits. The SUMMARY gives `git stash` / `git checkout -- data/checkpoints/platform` before he pulls.
